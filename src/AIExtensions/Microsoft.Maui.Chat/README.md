# Microsoft.Maui.Chat

`Microsoft.Maui.Chat` provides the chat model used by the .NET MAUI chat controls: conversations,
messages, participants, content, attachments, drafts, service contracts, and
`ChatComposerController`.

It is an experimental package. Use `Microsoft.Maui.Chat.Controls` to render a `ChatConversation`
with native XAML controls.

| Package | Purpose |
| --- | --- |
| `Microsoft.Maui.Chat` | Conversation and composer state |
| `Microsoft.Maui.Chat.Controls` | Native .NET MAUI XAML controls |

The core package requires .NET 10 only. Native rendering requires the .NET MAUI workload.
