# Bounded local reproduction handoff

The local operator owns a later fresh reproduction. This reference authorizes
nothing and contains no executable device command.

Preserve the original committed Markdown flow and plan sidecar bytes, Git
revision, plan revision and **separate** flow/plan digests. Retain the first
attempt report, execution manifest, JUnit and redacted trace, including
unsuccessful outcomes. A later pass must never overwrite the first failure.

Before any later run, the human Workbench reviewer must bind its separate grant
to the exact agent and process instance, current flow/plan revision/digests,
application build/source, platform/runtime, seed/reset, checkpoint, selectors
and actions. Never choose the first device or infer approval from chat.
When a trusted native client is unavailable, stop at the inert handoff.

A unique app-owned AutomationId is required. Repeated/virtualized items need
AutomationId + collectionScope + stableItemKey; no text/index/coordinate fallback.
App-owned identity, reset and oracle gaps go to the **app developer**, not to a
selector-repair guess. A destructive or non-replayable flow requires a separately
reviewed one-shot path and never automatic retry or repair validation.

Strict CI correspondence requires complete flow, plan, application-source,
runtime, checkpoint, seed, failure and step facts. Missing source fingerprints
mean **indeterminate**, even when both failures say locator-not-found.
An independent local observation may support its own diagnosis, but cannot
retroactively attest the imported artifact. Attestation and matching metadata
are not execution or repair authority.

Required business oracles must be independent of the UI channel being driven.
Record UI outcome, independent verification, cleanup and secondary failures
separately. Unknown completion is not a retry instruction.

Platform ownership is separate: Windows needs an active desktop; Apple runtime
work belongs to a provisioned macOS operator. Physical iOS is unavailable until
a signed-device harness exists; never substitute simulator evidence.

The final packet names the evidence custodian, app developer, local operator and
human reviewer, plus every unresolved prerequisite. No repair proposal or source
edit is created by this handoff.
